# SentinelID

## Project Overview
SentinelID is a web-based application designed for facial recognition security solutions. It offers a user-friendly interface for accessing security features, including logging in to a facial recognition system. The project combines modern web technologies, interactive UI elements, and responsive design to ensure accessibility across various devices.

## Installation
To set up the SentinelID project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <repository_url>
   ```

2. **Navigate into the project directory:**
   ```bash
   cd sentinelid
   ```

3. **Open the `index.html` or `index (3).html` file in your browser:**
   You can open the HTML files directly from your file system in a web browser to view and interact with the application.

## Usage
Once you have opened the application in your web browser, you can:
- **Navigate the website** to explore the solution, how it works, pricing, and more.
- **Login** using the provided form on the right panel, entering your username and password. 
- If you forget your password, use the "Esqueceu sua senha!" link for assistance.

## Features
- High-precision facial recognition security features.
- User authentication through a login interface.
- Responsive design optimized for both desktop and mobile devices.
- CSS styling leveraging Tailwind CSS for enhancing UI/UX.
- Dynamic elements for interaction and user engagement.

## Dependencies
This project does not have a `package.json` file; however, it utilizes the following external libraries hosted on CDNs:
- [Tailwind CSS](https://tailwindcss.com/) for styling.
- [React](https://reactjs.org/) and [ReactDOM](https://reactjs.org/) for building the UI components.
- [Babel](https://babeljs.io/) for JavaScript transpiling.
- [Font Awesome](https://fontawesome.com/) for vector icons.
- Google Fonts (**Inter**) for typography.

## Project Structure
The project structure consists of the following key files:

- `index.html`: Main entry point for the application featuring the login interface along with branding, navigation, and user prompts.
- `index (3).html`: A variant of the main entry point that potentially showcases an alternative layout or design.

### File Details:

  - Contains the HTML structure and embedded React components.

  - A responsive UI built using standard HTML and CSS, focusing on a straightforward user experience for accessing facial recognition services.

## Conclusion
SentinelID provides a compelling solution for businesses seeking a modern security framework based on facial recognition technology.
